title: "Beyond the Best: How to Judge True Model Adequacy"
author: yurongh2
---

A standard model-selection criterion (such as AIC, BIC, or Cp) will always select a "best" model among a set of candidates. However, this relative optimum does not guarantee that the model adequately explains the data. The chosen model might suffer from severe residual heteroscedasticity, nonlinearity, or non‑independence, violations that invalidate standard errors and p‑values. So how should we judge whether a model is truly adequate?
